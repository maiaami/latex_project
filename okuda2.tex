\section{はじめに}
本レポートでは確率論における大数の弱法則を述べる．大数の弱法則は，独立同分布な確率変数列の平均が母平均に収束することを保証するものであり，統計学や確率論の基礎的な結果である．
端的に言えば，ある確率変数の期待値が存在する場合，独立同分布な確率変数の平均はその期待値に近づくことを意味する．
サイコロで考えてみると，サイコロを何度も振ったときの目の平均が理論上の期待値である $3.5$ に近づくということを主張している．
この法則は直感的には当たり前のように思えるかもしれないが，その厳密な証明には確率論の基本的な概念や定理が必要であり，
本稿で紹介する「一番条件の緩い」大数の弱法則に至るまでには，その前段としていくつかのステップを踏まなければならない．
\section{確率収束の定義とゴールの紹介}
サイコロを振る回数を増やしていくとその平均が3.5に近づいていくと言ったはいいものの，例えばn会振った時の平均の出目は確率変数であるため
，その平均が3.5に近づくとはどういうことなのかを定義する必要がある.確率論の中には収束の概念がいくつかあり，ここでは確率収束を定義する．
\begin{dfn}[確率収束]
  確率変数列 $\{X_n\}$ が確率変数 $X$ に収束するとは，任意の $\varepsilon > 0$ に対して
  \[
    \lim_{n \to \infty} P(|X_n - X| \geq \varepsilon) = 0
  \]
  が成り立つことをいう．
\end{dfn}

\begin{tcolorbox}[
    colback=gray!15,       % 薄いグレー（15%の濃さ）
    colframe=gray!15,      % 枠線も同じ色にして実質線なしに
    arc=1mm,               % 好みで少しだけ角を丸く
    left=4mm, right=4mm,   % 左右の余白を少し広めに
    top=4mm, bottom=4mm
]
\textbf{【目指すゴール：大数の弱法則】}\\
$X_1, X_2, \dots$ を期待値が存在する（$E[|X_i|] < \infty$）独立同分布な確率変数列とし，$\mu = E[X_i]$ とする．
このとき，標本平均 $\bar{X}_n = \frac{X_1 + X_2 + \cdots + X_n}{n}$ は $\mu$ に確率収束する．すなわち，
\[
  \frac{S_n}{n} \xrightarrow{P} \mu \quad (n \to \infty)
\]
\end{tcolorbox}
これは一見シンプルな主張に見えるが，実は「期待値が存在する」という非常に緩い条件だけでこれを証明するのは一筋縄ではいかない．
そこでまずは，もう少し条件を厳しくした（例えば「分散が有限である」など）扱いやすいケースから出発し，徐々にこの最終目標へと迫っていくことにする．

\section{分散が有限な場合の大数の弱法則}

最終目標である「期待値の存在のみ」という条件はハードルが高いため，まずは「分散が有限である」という扱いやすい足がかりから出発しよう．このセクションで超えるべき最初のハードル（サブゴール）は以下の通りである．

    colframe=black,         % 枠線は黒

]
  $X_1, X_2, \dots$ を，$E(X_i) = \mu$，$\mathrm{var}(X_i) \le C < \infty$ をみたす無相関な確率変数列とする．このとき $S_n = X_1 + \cdots + X_n$ とおくと，$n \to \infty$ のとき $S_n/n$ は $\mu$ に2次平均収束かつ確率収束する.
\end{tcolorbox}

この主張は，のちに証明する最終目標（大数の弱法則）に比べると，「分散が有限（$\mathrm{var}(X_i) \le C$）」という強い条件が付いている．では，このサブゴールを達成するために，まずは必要となる「2次平均収束」の定義と，証明の強力な武器となる「チェビシェフの不等式」を準備していく．

\begin{thm}\
\textbf{チェビシェフの不等式}\\
  $\phi:\R \to \R$ が非負で，$A\in\mathbb{R}$ に対して，$i_A=\inf\{\phi(x):x\in A\}$とおく．このとき，任意の確率変数 $X$ に対して
    \[i_A P(X\in A) \leq E(\phi(X)\1_{X\in A}) \leq E(\phi(X))\]
    が成り立つ．  
\end{thm}
\begin{proof}
  $i_A$ は $A$ 上での $\phi$ の下限であるから，任意の $x\in A$ に対して $\phi(x)\geq i_A$ が成り立つ．したがって，$X\in A$ のとき $\phi(X)\geq i_A$ であることから，
  \[
    i_A \1_{X\in A} \leq \phi(X)\1_{X\in A} \leq \phi(X)
  \]
  が成り立つことから，期待値を取っても不等式が成り立つことがわかる．
\end{proof}

\begin{lem}
  $p>0$に対して，$E(|X|^p)< \rightarrow0$ ならば，$X_n$ は $0$ に確率収束する．
\end{lem}
\begin{proof}
  チェビシェフの不等式において， $\phi(x)=|x|^p$，$A=\{x:|x|\geq \varepsilon\}$ とおくと，$i_A=\inf\{|x|^p:|x|\geq \varepsilon\}=\varepsilon^p$ であるから， 
  \[
    \varepsilon^p P(|X_n| \geq \varepsilon) =\varepsilon^p P(|X_n|^p \geq \varepsilon^p)\leq E(|X_n|^p)
  \]
  が成り立つ．$E(|X_n|^p) \to 0$ であることから，右辺は $n \to \infty$ のとき $0$ に収束する．したがって，$X_n$ は $0$ に確率収束する．
\end{proof} 

\begin{dfn}[2次平均収束]
  確率変数列 $\{X_n\}$ が確率変数 $X$ に \textbf{2次平均収束} するとは，次の条件を満たすことをいう：
  \[
    \lim_{n \to \infty} E\left[(X_n - X)^2\right] = 0.
  \] 
\end{dfn}

さて，ここまでに述べてきた材料を用いることで，分散が有限な場合の大数の弱法則を証明することができる．改めて定理として述べると，次のようになる． 
\begin{thm}[$L^2$弱法則]
  $X_1, X_2, \dots$ を，$E(X_i) = \mu$，$\mathrm{var}(X_i) \le C < \infty$ をみたす無相関な確率変数列とする．このとき $S_n = X_1 + \cdots + X_n$ とおくと，$n \to \infty$ のとき $S_n/n$ は $\mu$ に2次平均収束かつ確率収束する.
\end{thm}
\begin{proof}
  
  まず，$S_n/n$ の分散を計算する．無相関な確率変数列に対しては，分散の加法性が成り立つことが知られている．したがって，
  \[
    \mathrm{var}\left(\frac{S_n}{n}\right) = \frac{1}{n^2} \mathrm{var}(S_n) = \frac{1}{n^2} \sum_{i=1}^n \mathrm{var}(X_i) \leq \frac{1}{n^2} \sum_{i=1}^n C = \frac{C}{n}.
  \]
  よって，$E\left[\left(\frac{S_n}{n} - \mu\right)^2\right] = \mathrm{var}\left(\frac{S_n}{n}\right) \leq \frac{C}{n}$ である．
  $n \to \infty$ のとき，$\frac{C}{n} \to 0$ であるから，$E\left[\left(\frac{S_n}{n} - \mu\right)^2\right] \to 0$ が成り立つ．
  したがって，$S_n/n$ は $\mu$ に2次平均収束する．
  
  確率収束については．補題3.2より，$E\left[\left(\frac{S_n}{n} - \mu\right)^2\right] \to 0$ であることから，$\frac{S_n}{n}$ は $\mu$ に確率収束する．
\end{proof}

\section{応用例：多項式近似（Bernstein 多項式）}

\begin{ex}[例2.2.4（多項式近似）]
$f$ を $[0,1]$ 上の連続関数とし，$f_n$ を
\[
  f_n(x) = \sum_{m=0}^n \binom{n}{m} x^m (1-x)^{n-m} f\!\left(\frac{m}{n}\right), \qquad
  \binom{n}{m} = \frac{n!}{m!(n-m)!}
\]
で与えられる $f$ に対応する $n$ 次 Bernstein 多項式とすると，$n \to \infty$ のとき次が成り立つ．
\[
  \sup_{x \in [0,1]} |f_n(x) - f(x)| \to 0
\]
\end{ex}

\begin{proof}

  $X_1,\dots,X_n$ を $[0,1]$ 上の確率変数で，$P(X_i=1)=x$，$P(X_i=0)=1-x$ であるとする．このとき，$S_n = X_1 + \cdots + X_n$とおくと，$S_n$ は二項分布 $B(n,x)$ に従う．したがって，
  \[
    P(S_n = m) = \binom{n}{m} x^m (1-x)^{n-m}
  \]
  である．したがって，
  \[
    E\!\left[f\!\left(\frac{S_n}{n}\right)\right] = \sum_{m=0}^n P(S_n = m) f\!\left(\frac{m}{n}\right) = \sum_{m=0}^n \binom{n}{m} x^m (1-x)^{n-m} f\!\left(\frac{m}{n}\right) = f_n(x)
  \]
  ということになる。これを用いると
  \[
    |f_n(x) - f(x)|=\left|E\!\left[f\!\left(\frac{S_n}{n}\right)\right] - f(x)\right|\leq E\!\left[\left|f\!\left(\frac{S_n}{n}\right) - f(x)\right|\right]
  \]
  となる。ところで，$f$ は 連続関数であるから，閉区間$[0,1]$ 上で一様連続である．よって任意の $\varepsilon>0$ に対して，ある $\delta>0$ が存在して，$|x-y|<\delta$ ならば $|f(x)-f(y)|<\varepsilon$ が成り立つ．
  一方，$M=\sup_{x\in[0,1]}|f(x)|$とおけば，$|S_n/n - x|\geq \delta$ のとき，$|f(S_n/n)-f(x)|\leq 2M$ が成り立つ．
  したがって，次のように分けて評価できる：
  \begin{align*}
    E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \right] 
    &= E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \boldsymbol{1}_{\{|S_n/n - x| < \delta\}} \right] + E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \boldsymbol{1}_{\{|S_n/n - x| \geq \delta\}} \right] \\
    &\leq \varepsilon+ 2M P\left( \left| \frac{S_n}{n} - x \right| \geq \delta \right)
  \end{align*}
  となる。
  ところで，$S_n$は確率変数$X_1,\dots,X_n$の和であり，$E(X_i)=x$，$\mathrm{var}(X_i)=x(1-x)\leq 1/4$で有限であることから，$L_2$弱収束を用いることができて，$S_n/n$は$x$に確率収束する。つまり，$n\to\infty$のとき，$P(|S_n/n - x| \geq \delta) \to 0$が成り立つ。したがって，十分大きな$n$に対して
\[
  E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \right] < \varepsilon
\]
が成り立つ。$\delta$は$x$に依存しないので，$x\in[0,1]$に対して一様に評価できる。
よって，$n\to\infty$のとき，$\sup_{x\in[0,1]} |f_n(x) - f(x)| \to 0$が成り立つことが示された。


\end{proof}



\section{無相関な確率変数列と分散}

\begin{thm}
$E(X_i^2) < \infty$ である確率変数列 $X_1,\dots,X_n$ が無相関であれば，
\[
  \mathrm{var}(X_1 + \cdots + X_n) = \mathrm{var}(X_1) + \cdots + \mathrm{var}(X_n)
\]
が成り立つ．
\end{thm}

\begin{proof}
$\mu_i = E(X_i)$，$S_n = \sum_{i=1}^n X_i$ とおく．$E(S_n) = \sum_{i=1}^n \mu_i$ だから，分散の定義を用い，和の2乗を積の形で書いて展開すると，
\begin{align*}
  \mathrm{var}(S_n)
  &= E\!\left((S_n - E(S_n))^2\right)
   = E\!\left(\left\{\sum_{i=1}^n (X_i - \mu_i)\right\}^2\right) \\
  &= E\!\left(\sum_{i=1}^n \sum_{j=1}^n (X_i - \mu_i)(X_j - \mu_j)\right) \\
  &= \sum_{i=1}^n E\!\left((X_i - \mu_i)^2\right) + 2\sum_{i=1}^n \sum_{j=1}^{i-1} E\!\left((X_i - \mu_i)(X_j - \mu_j)\right)
\end{align*}
となる．ただし，最後の等式では対角の項 $i=j$ を分け，$1 \le i < j \le n$ に関する和と $1 \le j < i \le n$ に関する和が等しいことを用いた．
この第2項を展開すると，$X_i$ と $X_j$ が無相関であることから，次のようになる
\[
  E\!\left((X_i - \mu_i)(X_j - \mu_j)\right)
  = E(X_iX_j) - \mu_i E(X_j) - \mu_j E(X_i) + \mu_i\mu_j
  = E(X_iX_j) - \mu_i\mu_j = 0
\]
\end{proof}
