\section{はじめに}
本レポートでは確率論における大数の弱法則を述べる．大数の弱法則は，独立同分布な確率変数列の平均が母平均に収束することを保証するものであり，統計学や確率論の基礎的な結果である．
端的に言えば，ある確率変数の期待値が存在する場合，独立同分布な確率変数の平均はその期待値に近づくことを意味する．
サイコロで考えてみると，サイコロを何度も振ったときの目の平均が理論上の期待値である $3.5$ に近づくということを主張している．
この法則は直感的には当たり前のように思えるかもしれないが，その厳密な証明には確率論の基本的な概念や定理が必要であり，
本稿で紹介する「一番条件の緩い」大数の弱法則に至るまでには，その前段としていくつかのステップを踏まなければならない．
\section{確率収束の定義とゴールの紹介}
サイコロを振る回数を増やしていくとその平均が3.5に近づいていくと言ったはいいものの，例えばn会振った時の平均の出目は確率変数であるため
，その平均が3.5に近づくとはどういうことなのかを定義する必要がある.確率論の中には収束の概念がいくつかあり，ここでは確率収束を定義する．
\begin{dfn}[確率収束]
  確率変数列 $\{X_n\}$ が確率変数 $X$ に収束するとは，任意の $\varepsilon > 0$ に対して
  \[
    \lim_{n \to \infty} P(|X_n - X| \geq \varepsilon) = 0
  \]
  が成り立つことをいう．
\end{dfn}

\begin{tcolorbox}[
    colback=gray!15,       % 薄いグレー（15%の濃さ）
    colframe=gray!15,      % 枠線も同じ色にして実質線なしに
    arc=1mm,               % 好みで少しだけ角を丸く
    left=4mm, right=4mm,   % 左右の余白を少し広めに
    top=4mm, bottom=4mm
]
\textbf{【目指すゴール：大数の弱法則】}\\
$X_1, X_2, \dots$ を期待値が存在する（$E[|X_i|] < \infty$）独立同分布な確率変数列とし，$\mu = E[X_i]$ とする．
このとき，標本平均 $\bar{X}_n = \frac{X_1 + X_2 + \cdots + X_n}{n}$ は $\mu$ に確率収束する．すなわち，
\[
  \frac{S_n}{n} \xrightarrow{P} \mu \quad (n \to \infty)
\]
\end{tcolorbox}
これは一見シンプルな主張に見えるが，実は「期待値が存在する」という非常に緩い条件だけでこれを証明するのは一筋縄ではいかない．
そこでまずは，もう少し条件を厳しくした（例えば「分散が有限である」など）扱いやすいケースから出発し，徐々にこの最終目標へと迫っていくことにする．

\section{分散が有限な場合の大数の弱法則}

最終目標である「期待値の存在のみ」という条件はハードルが高いため，まずは「分散が有限である」という扱いやすい足がかりから出発しよう．このセクションで超えるべき最初のハードル（サブゴール）は以下の通りである．

]
  $X_1, X_2, \dots$ を，$E(X_i) = \mu$，$\mathrm{var}(X_i) \le C < \infty$ をみたす無相関な確率変数列とする．このとき $S_n = X_1 + \cdots + X_n$ とおくと，$n \to \infty$ のとき $S_n/n$ は $\mu$ に2次平均収束かつ確率収束する.
\end{tcolorbox}

この主張は，のちに証明する最終目標（大数の弱法則）に比べると，「分散が有限（$\mathrm{var}(X_i) \le C$）」という強い条件が付いている．では，このサブゴールを達成するために，まずは必要となる「2次平均収束」の定義と，証明の強力な武器となる「チェビシェフの不等式」を準備していく．

\begin{thm}\
\textbf{チェビシェフの不等式}\\
  $\phi:\R \to \R$ が非負で，$A\in\mathbb{R}$ に対して，$i_A=\inf\{\phi(x):x\in A\}$とおく．このとき，任意の確率変数 $X$ に対して
    \[i_A P(X\in A) \leq E(\phi(X)\1_{X\in A}) \leq E(\phi(X))\]
    が成り立つ．  
\end{thm}
\begin{proof}
  $i_A$ は $A$ 上での $\phi$ の下限であるから，任意の $x\in A$ に対して $\phi(x)\geq i_A$ が成り立つ．したがって，$X\in A$ のとき $\phi(X)\geq i_A$ であることから，
  \[
    i_A \1_{X\in A} \leq \phi(X)\1_{X\in A} \leq \phi(X)
  \]
  が成り立つことから，期待値を取っても不等式が成り立つことがわかる．
\end{proof}

\begin{lem}
  $p>0$に対して，$E(|X|^p)< \rightarrow0$ ならば，$X_n$ は $0$ に確率収束する．
\end{lem}
\begin{proof}
  チェビシェフの不等式において， $\phi(x)=|x|^p$，$A=\{x:|x|\geq \varepsilon\}$ とおくと，$i_A=\inf\{|x|^p:|x|\geq \varepsilon\}=\varepsilon^p$ であるから， 
  \[
    \varepsilon^p P(|X_n| \geq \varepsilon) =\varepsilon^p P(|X_n|^p \geq \varepsilon^p)\leq E(|X_n|^p)
  \]
  が成り立つ．$E(|X_n|^p) \to 0$ であることから，右辺は $n \to \infty$ のとき $0$ に収束する．したがって，$X_n$ は $0$ に確率収束する．
\end{proof} 

\begin{dfn}[2次平均収束]
  確率変数列 $\{X_n\}$ が確率変数 $X$ に \textbf{2次平均収束} するとは，次の条件を満たすことをいう：
  \[
    \lim_{n \to \infty} E\left[(X_n - X)^2\right] = 0.
  \] 
\end{dfn}

さて，ここまでに述べてきた材料を用いることで，分散が有限な場合の大数の弱法則を証明することができる．改めて定理として述べると，次のようになる． 
\begin{thm}[$L^2$弱法則]
  $X_1, X_2, \dots$ を，$E(X_i) = \mu$，$\mathrm{var}(X_i) \le C < \infty$ をみたす無相関な確率変数列とする．このとき $S_n = X_1 + \cdots + X_n$ とおくと，$n \to \infty$ のとき $S_n/n$ は $\mu$ に2次平均収束かつ確率収束する.
\end{thm}
\begin{proof}
  
  まず，$S_n/n$ の分散を計算する．無相関な確率変数列に対しては，分散の加法性が成り立つことが知られている．したがって，
  \[
    \mathrm{var}\left(\frac{S_n}{n}\right) = \frac{1}{n^2} \mathrm{var}(S_n) = \frac{1}{n^2} \sum_{i=1}^n \mathrm{var}(X_i) \leq \frac{1}{n^2} \sum_{i=1}^n C = \frac{C}{n}.
  \]
  よって，$E\left[\left(\frac{S_n}{n} - \mu\right)^2\right] = \mathrm{var}\left(\frac{S_n}{n}\right) \leq \frac{C}{n}$ である．
  $n \to \infty$ のとき，$\frac{C}{n} \to 0$ であるから，$E\left[\left(\frac{S_n}{n} - \mu\right)^2\right] \to 0$ が成り立つ．
  したがって，$S_n/n$ は $\mu$ に2次平均収束する．
  
  確率収束については．補題3.2より，$E\left[\left(\frac{S_n}{n} - \mu\right)^2\right] \to 0$ であることから，$\frac{S_n}{n}$ は $\mu$ に確率収束する．
\end{proof}

\section{応用例：多項式近似（Bernstein 多項式）}

\begin{ex}[例2.2.4（多項式近似）]
$f$ を $[0,1]$ 上の連続関数とし，$f_n$ を
\[
  f_n(x) = \sum_{m=0}^n \binom{n}{m} x^m (1-x)^{n-m} f\!\left(\frac{m}{n}\right), \qquad
  \binom{n}{m} = \frac{n!}{m!(n-m)!}
\]
で与えられる $f$ に対応する $n$ 次 Bernstein 多項式とすると，$n \to \infty$ のとき次が成り立つ．
\[
  \sup_{x \in [0,1]} |f_n(x) - f(x)| \to 0
\]
\end{ex}

\begin{proof}

  $X_1,\dots,X_n$ を $[0,1]$ 上の確率変数で，$P(X_i=1)=x$，$P(X_i=0)=1-x$ であるとする．このとき，$S_n = X_1 + \cdots + X_n$とおくと，$S_n$ は二項分布 $B(n,x)$ に従う．したがって，
  \[
    P(S_n = m) = \binom{n}{m} x^m (1-x)^{n-m}
  \]
  である．したがって，
  \[
    E\!\left[f\!\left(\frac{S_n}{n}\right)\right] = \sum_{m=0}^n P(S_n = m) f\!\left(\frac{m}{n}\right) = \sum_{m=0}^n \binom{n}{m} x^m (1-x)^{n-m} f\!\left(\frac{m}{n}\right) = f_n(x)
  \]
  ということになる。これを用いると
  \[
    |f_n(x) - f(x)|=\left|E\!\left[f\!\left(\frac{S_n}{n}\right)\right] - f(x)\right|\leq E\!\left[\left|f\!\left(\frac{S_n}{n}\right) - f(x)\right|\right]
  \]
  となる。ところで，$f$ は 連続関数であるから，閉区間$[0,1]$ 上で一様連続である．よって任意の $\varepsilon>0$ に対して，ある $\delta>0$ が存在して，$|x-y|<\delta$ ならば $|f(x)-f(y)|<\varepsilon$ が成り立つ．
  一方，$M=\sup_{x\in[0,1]}|f(x)|$とおけば，$|S_n/n - x|\geq \delta$ のとき，$|f(S_n/n)-f(x)|\leq 2M$ が成り立つ．
  したがって，次のように分けて評価できる：
  \begin{align*}
    E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \right] 
    &= E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \boldsymbol{1}_{\{|S_n/n - x| < \delta\}} \right] + E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \boldsymbol{1}_{\{|S_n/n - x| \geq \delta\}} \right] \\
    &\leq \varepsilon+ 2M P\left( \left| \frac{S_n}{n} - x \right| \geq \delta \right)
  \end{align*}
  となる。
  ところで，$S_n$は確率変数$X_1,\dots,X_n$の和であり，$E(X_i)=x$，$\mathrm{var}(X_i)=x(1-x)\leq 1/4$で有限であることから，$L_2$弱収束を用いることができて，$S_n/n$は$x$に確率収束する。つまり，$n\to\infty$のとき，$P(|S_n/n - x| \geq \delta) \to 0$が成り立つ。したがって，十分大きな$n$に対して
\[
  E\left[ \left| f\left(\frac{S_n}{n}\right) - f(x) \right| \right] < \varepsilon
\]
が成り立つ。$\delta$は$x$に依存しないので，$x\in[0,1]$に対して一様に評価できる。
よって，$n\to\infty$のとき，$\sup_{x\in[0,1]} |f_n(x) - f(x)| \to 0$が成り立つことが示された。

\end{proof}


\section{三角配列に対する弱法則と一般化}
\begin{thm}[三角配列に対する弱法則]
各 $n$ に対し，$X_{n,k}$，$1 \le k \le n$ は独立とする．$b_n > 0$，$b_n \to \infty$ をみたす $b_n$ に対して $\bar{X}_{n,k} = X_{n,k} 1_{(|X_{n,k}| \le b_n)}$ とおき，$n \to \infty$ のとき次が成り立つと仮定する．
  \begin{enumerate}
    \item[(i)] $\displaystyle \sum_{k=1}^n P(|X_{n,k}| > b_n) \to 0$
    \item[(ii)] $\displaystyle b_n^{-2} \sum_{k=1}^n E(\bar{X}_{n,k}^2) \to 0$
  \end{enumerate}
このとき，$S_n = X_{n,1} + \cdots + X_{n,n}$ とし，$a_n = \sum_{k=1}^n E(\bar{X}_{n,k})$ とおくと，
\[
\frac{S_n - a_n}{b_n} \to 0
\]
が確率収束の意味で成り立つ．
\end{thm}
\begin{proof}
  $\bar{S}_n = \bar{X}_{n,1} + \cdots + \bar{X}_{n,n}$ とおく．
  $\frac{S_n - a_n}{b_n}$の収束について聞かれているから，これが$\varepsilon$以上になる確率を考えてみると，次のように評価できる．
  \begin{align*}
    P\left(\left|\frac{S_n - a_n}{b_n}\right| \ge \varepsilon\right)
    &=P\left(\left|\frac{S_n - a_n}{b_n}\right| \ge \varepsilon, S_n = \bar{S}_n\right) + P\left(\left|\frac{S_n - a_n}{b_n}\right| \ge \varepsilon, S_n \neq \bar{S}_n\right)\\
    &\le P(S_n \neq \bar{S}_n) + P\left(\left|\frac{\bar{S}_n - a_n}{b_n}\right| \ge \varepsilon\right)
  \end{align*}
  この第一項について，$S_n \neq \bar{S}_n$ となっていれば，少なくとも1つの $|X_{n,k}|$ が $b_n$ を上回り，$\bar{X}_{n,k} \neq X_{n,k}$となる（逆は必ずしも成立しない．例えば元の確率変数列のある要素$X_{n,k}$のみが$b_n>0$を上回った場合は$\bar{X}_{n,k}=0$より$\bar{S}_n$は$S_n$より小さくなるが，加えて別の確率変数$X_{n,j}$が$-b_n$を下回った場合は$\bar{X}_{n,j} = 0$となるので，$\bar{S}_n$は大きくなる．この差分が打ち消し合うことで偶然$S_n = \bar{S}_n$となる場合がある）．\\したがって，ボンフェロー二の不等式および仮定(i)より，次のように評価できる．
  \[
    P(S_n \neq \bar{S}_n) \leq P\left(\bigcup_{k=1}^n \{\bar{X}_{n,k} \neq X_{n,k}\}\right) \le \sum_{k=1}^n P(|X_{n,k}| > b_n) \to 0
  \]
  第2項について，チェビシェフの不等式を用いると，
  \begin{align*}
  P\left(\left|\frac{\bar{S}_n - a_n}{b_n}\right| \ge \varepsilon\right) 
  &\le \frac{1}{\varepsilon^2} E\left[\left(\frac{\bar{S}_n - a_n}{b_n}\right)^2\right] = \frac{1}{\varepsilon^2 b_n^2} E\left[(\bar{S}_n - a_n)^2\right] = \frac{1}{\varepsilon^2 b_n^2} \mathrm{var}(\bar{S}_n)\\
  &= \frac{1}{\varepsilon^2 b_n^2} \sum_{k=1}^n \mathrm{var}(\bar{X}_{n,k}) \le \frac{1}{\varepsilon^2 b_n^2} \sum_{k=1}^n E(\bar{X}_{n,k}^2) \to 0
  \end{align*}
  最後の不等式は，一般に$\mathrm{var}(X)=E(X^2) - (E(X))^2 \leq E(X^2)$となることを用いた．
  よって第1項，第2項ともに $n \to \infty$ のとき $0$ に収束することが示されたので，結論として
  \[
    P\left(\left|\frac{S_n - a_n}{b_n}\right| \ge \varepsilon\right) \to 0
  \]
  が成り立つ．
\end{proof}

さて，この定理を用いることで，通常の確率変数列に対しても弱法則を示すことができる．
\begin{thm}[弱法則の一般化]
$X_1, X_2, \dots$ を
\[
  xP(|X_i| \ge x) \to 0, \qquad x \to \infty
\]
をみたす i.i.d.\ とする．このとき，$S_n = X_1 + \cdots + X_n$，$\mu_n = E(X_1 1_{(|X_1| \le n)})$ とおくと，$S_n/n - \mu_n$ は $0$ に確率収束する．
\end{thm}
\begin{proof}
  
三角配列に対する弱法則について$b_n = n$，$X_{n,k} = X_k$ とおいて考えてみる．この場合，$a_n$に相当するのは$\sum_{k=1}^n E(\bar{X}_k)=n\mu_n$であるから，条件(i)(ii)が示せればよいことになる．\\
条件(i)については，
\[
\sum_{k=1}^n P(|X_{n,k}| > b_n) = n P(|X_1| > n) \to 0
\]
が成り立つ．$X_1$ は i.i.d.\ であるため，$P(|X_{n,k}| > b_n) = P(|X_k| > n) = P(|X_1| > n)$ が成り立つ．）\\
条件(ii)については，$n^{-2}\cdot\sum_{k=1}^n E(\bar{X}_{n,k}^2) = n^{-2}\cdot n E(\bar{X}_{n,1}^2) \to 0$を示せればよい．
これを示すために次の補題を用意する．
  \begin{sidebarside}
  \begin{lem}
    $Y \ge 0$，$p > 0$ ならば，
    \[
    E(Y^p) = \int_0^\infty p y^{p-1} P(Y > y)\, dy
    \]
    が成り立つ．
  \end{lem}
  \begin{proof}
    \begin{align*}
    E(Y^p)&=\int_{\Omega} Y^p dP=\int_{\Omega}\int_{0}^{Y}p y^{p-1} dy dP=\int_\Omega\int_{0}^{\infty}p y^{p-1} 1_{(Y>y)}dy dP\\
    \intertext{ここでFubiniの定理を用いると積分順序を交換することができ，}
    &=\int_{0}^{\infty}\int_\Omega p y^{p-1} 1_{(Y>y)}dP dy=\int_{0}^{\infty}p y^{p-1}\int_\Omega 1_{(Y>y)}dPdy=\int_{0}^{\infty}p y^{p-1}P(Y>y)dy
    \end{align*}
  \end{proof}
  \end{sidebarside}
さて，本筋に戻り，この補題を用いて$E(\bar{X}_{n,1}^2)$を変形していくと次のようになる
\[
E(\bar{X}_{n,1}^2)=E(|\bar{X}_{n,1}|^2)=\int_{0}^{\infty}2xP(|\bar{X}_{n,1}|>x)dx
\]
ここで，条件(i)を用いるために$P(|\bar{X}_{n,1}|>x)$をバー無しの$|X_{n,1}|$を用いて評価したい。$\bar{X}_{n,k} = X_{n,k} 1_{(|X_{n,k}| \le n)}$だったので，$P(|\bar{X}_{n,1}|>x)$は，$x\ge n$ならば$0$になるし，$x\le n$ならば$P(|X_{n,1}|>x)-P(|X_{n,1}|>n)$に等しい（すなわちこの第1項で上から抑えられる）。したがって
\begin{align*}
\int_{0}^{\infty}2xP(|\bar{X}_{n,1}|>x)dx &= \int_{0}^{n}2xP(|\bar{X}_{n,1}|>x)dx+\int_{n}^{\infty}2xP(|\bar{X}_{n,1}|>x)dx\\
&\le \int_{0}^{n}2xP(|X_{n,1}|>x)dx=\int_{0}^{n}2xP(|X_1|>x)dx
\end{align*}
ここで，考えるべきなのは$n^{-1}\cdot E(\bar{X}_{n,1}^2) \to 0$であることを思い出すと，$n\to\infty$で
\[
\frac{E(\bar{X}_{n,1}^2)}{n}\le \frac{1}{n}\int_{0}^{n}2xP(|X_1|>x)dx\to\infty
\]
となることを示せれば良い。
$g(x)=2xP(|X_1|>x)$とすると$0<g(x)<2x$であり，$x\to\infty$で$g(x)\to 0$である．したがって，$\sup(g(x))<\infty$である．$g_n(x)=g(nx)$とおくと，$g_n$は有界で$g_n(x)\xrightarrow[n\to\infty]{} 0$だから，有界収束定理が適用でき，
\[
\lim_{n\to\infty}\frac{1}{n}\int_{0}^{n}2xP(|X_1|>x)dx=\lim_{n\to\infty}\int_{0}^{1}g_n(x)dx=\int_{0}^{1}\lim_{n\to\infty}g_n(x)dx=0
\]
以上で条件(ii)も成立していることを確かめられたので，定理5.2が示された.

\end{proof}

\section{最も条件の緩い大数の弱法則}
\begin{thm}
$X_1,X_2\cdots$を$E(|X_i|)<\infty$であるi.i.d.とし，$S_n=X_1+\cdots+X_n$，$\mu=E(X_1)$とおく．\\このとき$n\to\infty$で
\[
S_n/n\xrightarrow{P}\mu
\]
\end{thm}
\begin{proof}
まず，チェビシェフの不等式から
\[
  xP(|X_1| > x) \le E\!\left(|X_1| 1_{(|X_1|>x)}\right)
\]
が成り立つ．この右辺が0に収束することを示したい．\\
各 $\omega \in \Omega$ を固定すると，$E(|X_1|) < \infty$ より $|X_1(\omega)| < \infty$ がほとんど確実に ($\text{a.s.}$) 成り立つ．
したがって，被積分関数を $f_x(\omega) = |X_1(\omega)| 1_{(|X_1(\omega)|>x)}$ とすると，$x \to \infty$ としたとき各点ごとにいつかは必ず $x$ が $|X_1(\omega)|$ を上回るため、
\[
  f_x(\omega) \to 0, \qquad x \to \infty \quad (\text{a.s.})
\]
となり，$f_x$が$0$にa.e.で収束する．
ここで，任意の $x > 0$ に対して $|f_x(\omega)| \le |X_1(\omega)|$ であり，仮定より $|X_1|$ は可積分であるから，ルベーグの優収束定理が適用できる．したがって，
\[
  \lim_{x \to \infty} xP(|X_1| > x) \le \lim_{x \to \infty} E\!\left(|X_1| 1_{(|X_1|>x)}\right) = E\left(\lim_{x \to \infty} f_x\right) = 0
\]
となる．よって定理5.2から
\[
\frac{S_n}{n}-\mu_n\xrightarrow{P} 0
\]

次に，$\mu_n\coloneqq E(X_1 1_{(|X_1|\leq n)})$とすると，$\mu_n\to\mu$となることを示す．$g_n(\omega)\coloneq X_1(\omega) 1_{(|X_1(\omega)| \le n)}$とすると，各$\omega$について，$n\to\infty$としたときにどこかで必ず$n$が$|X_1(\omega)|$を上回るため，
\[
  g_n(\omega)\to X_1(\omega), \qquad n\to\infty \quad (\text{a.s.})
\]
となる．したがって
\[
  \lim_{n\to\infty}\mu_n=\lim_{n\to\infty} E(X_1 1_{(|X_1|\leq n)})=E(\lim_{n\to\infty}X_1 1_{(|X_1|\leq n)})=E(X_1)=\mu
\]
となる．ところで任意の$\varepsilon$について，
\end{proof}




\section{無相関な確率変数列と分散}

\begin{thm}
$E(X_i^2) < \infty$ である確率変数列 $X_1,\dots,X_n$ が無相関であれば，
\[
  \mathrm{var}(X_1 + \cdots + X_n) = \mathrm{var}(X_1) + \cdots + \mathrm{var}(X_n)
\]
が成り立つ．
\end{thm}

\begin{proof}
$\mu_i = E(X_i)$，$S_n = \sum_{i=1}^n X_i$ とおく．$E(S_n) = \sum_{i=1}^n \mu_i$ だから，分散の定義を用い，和の2乗を積の形で書いて展開すると，
\begin{align*}
  \mathrm{var}(S_n)
  &= E\!\left((S_n - E(S_n))^2\right)
   = E\!\left(\left\{\sum_{i=1}^n (X_i - \mu_i)\right\}^2\right) \\
  &= E\!\left(\sum_{i=1}^n \sum_{j=1}^n (X_i - \mu_i)(X_j - \mu_j)\right) \\
  &= \sum_{i=1}^n E\!\left((X_i - \mu_i)^2\right) + 2\sum_{i=1}^n \sum_{j=1}^{i-1} E\!\left((X_i - \mu_i)(X_j - \mu_j)\right)
\end{align*}
となる．ただし，最後の等式では対角の項 $i=j$ を分け，$1 \le i < j \le n$ に関する和と $1 \le j < i \le n$ に関する和が等しいことを用いた．
この第2項を展開すると，$X_i$ と $X_j$ が無相関であることから，次のようになる
\[
  E\!\left((X_i - \mu_i)(X_j - \mu_j)\right)
  = E(X_iX_j) - \mu_i E(X_j) - \mu_j E(X_i) + \mu_i\mu_j
  = E(X_iX_j) - \mu_i\mu_j = 0
\]
\end{proof}
